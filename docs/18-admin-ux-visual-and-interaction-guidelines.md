# 后台管理系统体验统一化规范（Admin UX Refresh）

## 1. 文档目的

本文档用于定义 GovCMS 后台管理系统的统一视觉与交互规范，作为后续所有后台页面改版与新增页面设计的唯一基准。

本规范解决以下现状问题：

- 页面标题、表格、按钮、表单、弹窗在不同页面的视觉层级不一致
- 列表页、工作台页、弹窗页缺少统一结构与操作顺序
- 图标按钮、批量操作、状态标签、空状态等缺少统一约束
- 页面实现以单页为中心，缺少后台系统级体验标准

本阶段只定义规范，不直接改后台页面实现。

## 2. 适用范围

本规范适用于 GovCMS 后台管理系统，包括但不限于以下页面：

- 用户管理
- 栏目管理
- 站点管理
- 模板管理
- 导航管理
- 专题管理
- 媒体管理
- 发布中心
- 搜索运营

本规范不适用于：

- 门户前台页面
- 登录页品牌视觉升级
- 纯门户搜索结果页视觉规范

## 3. 视觉规范

### 3.1 字体体系

| 层级 | 用途 | 字号 | 字重 | 行高 | 颜色 |
| --- | --- | --- | --- | --- | --- |
| H1 | 页面标题 | 28px | 700 | 36px | `#0f172a` |
| H2 | 模块/卡片标题 | 18px | 600 | 28px | `#0f172a` |
| H3 | 区块次标题 | 16px | 600 | 24px | `#0f172a` |
| Body | 表格正文/表单正文/普通信息 | 14px | 400 | 22px | `#0f172a` |
| Meta | 辅助说明/时间/次级信息 | 12px | 400 | 18px | `#64748b` |
| Label | 表单标签/表头 | 13px | 500 | 20px | `#475569` |
| Badge | 状态标签 | 12px | 600 | 16px | 按状态色 |

固定规则：

- 一个页面只允许一个 H1
- 卡片标题统一使用 H2
- 表头、表单标签统一使用 Label，不与正文混用
- 辅助文案和提示统一使用 Meta

### 3.2 间距体系

| 场景 | 数值 |
| --- | --- |
| 页面区块间距 | 16px |
| 页面头部与正文间距 | 16px |
| 卡片内边距 | 16px |
| 大弹窗内边距 | 24px |
| 表单项纵向间距 | 16px |
| 表格单元格内边距 | 14px ~ 16px |
| 按钮组间距 | 8px / 12px |
| 搜索区控件间距 | 12px |

固定规则：

- 不同页面的主卡片外边距统一按 16px
- 同类操作按钮组默认使用 8px 间距
- 搜索筛选区默认使用 12px 间距
- 表单分组之间至少保留 16px 以上间距

### 3.3 颜色体系

| 语义 | 颜色 |
| --- | --- |
| 主色 | `#2563eb` |
| 主色深 | `#1d4ed8` |
| 成功 | `#166534` / `#dcfce7` |
| 警告 | `#b45309` / `#fef3c7` |
| 危险 | `#dc2626` / `#fee2e2` |
| 信息 | `#0f172a` / `#e2e8f0` |
| 边框 | `#e2e8f0` |
| 分割线 | `#f1f5f9` |
| 页面背景 | `#f8fafc` |
| 卡片背景 | `#ffffff` |
| 辅助文字 | `#64748b` |
| 禁用态 | `opacity: 0.6` + 禁用光标 |

固定规则：

- 主操作只使用主色按钮
- 危险操作只使用危险色按钮或危险确认弹窗
- 状态标签使用浅底深字，不使用高饱和纯色块

### 3.4 圆角与阴影

| 元素 | 圆角 |
| --- | --- |
| 主卡片 | 12px ~ 14px |
| 弹窗 | 16px |
| 输入框 / 下拉 | 8px ~ 10px |
| 主按钮 / 次按钮 | 10px |
| 图标按钮 | 6px |
| 标签 / 状态徽标 | 999px |

阴影规则：

- 页面卡片只使用轻阴影，避免大量浮层感
- 弹窗可以使用明显于卡片的阴影
- 表格容器优先使用边框，不依赖重阴影区分层级

### 3.5 图标规范

- 图标默认尺寸：16px ~ 18px
- “按钮 + 图标”优先使用左图标右文字
- 纯图标按钮仅用于：
  - 行内次级操作
  - 表格操作列
  - 关闭弹窗
- 危险操作若用户不可从上下文明确判断，必须使用“图标 + 文本”而不是纯图标
- 列表页高频操作优先文本按钮，不鼓励全部收缩成纯图标

## 4. 交互规范

### 4.1 列表页模式

标准结构固定为：

1. 页面头部（标题 + 页面说明 + 主操作）
2. 搜索/筛选区
3. 批量操作区（若存在）
4. 数据表格区
5. 分页区

固定规则：

- 搜索框放左侧，主操作放右侧或页面头部右上角
- 批量操作位于搜索筛选区下方或同一块内，不与单行操作混排
- 列表页默认必须包含空状态与加载状态
- 表格操作列顺序固定建议为：编辑 → 次级操作 → 危险操作

### 4.2 表单弹窗模式

标准结构固定为：

1. 标题区
2. 表单内容区
3. 底部操作区

固定规则：

- 主按钮放右侧，取消放左侧或次级按钮位
- 表单必须按信息分组展示，不做无结构长表单
- 校验失败优先使用就近提示 + 顶层消息组合
- 关闭按钮与取消按钮语义不同：
  - 关闭是视觉层动作
  - 取消是明确放弃当前编辑动作

### 4.3 工作台 / 双栏页面模式

适用于发布中心、搜索运营等页面。

标准结构固定为：

- 左侧：输入、筛选、主流程操作
- 右侧：状态、结果、统计、说明
- 底部：详情列表、日志、辅助信息

固定规则：

- 信息卡片必须分组命名明确
- 告警、失败、成功信息必须分层，不得混在同一块
- 工作台页应优先保证“先决策，再执行，再查看结果”的顺序

### 4.4 状态反馈规范

统一状态包括：

- 加载中
- 暂无数据
- 操作成功
- 操作失败
- 业务阻断
- 危险确认
- 权限不足

固定规则：

- 空状态必须提供简短解释，不允许只留空白
- 业务阻断文案必须可读，不使用技术术语替代业务解释
- 危险确认弹窗需说明后果，不只写“是否确认”
- 成功消息简短明确，失败消息优先显示后端返回业务原因

## 5. 页面模板规范

### 5.1 管理列表页模板

适用：用户、角色、权限、菜单、媒体、站点列表等。

固定区域：

- 页面头部
- 搜索筛选区
- 批量操作区
- 表格区
- 分页区

适用特点：

- 信息密度中等
- 支持批量操作
- 行内操作较多

### 5.2 管理列表 + 弹窗表单模板

适用：用户管理、栏目管理、站点管理等。

固定区域：

- 列表页结构同上
- 弹窗表单分组
- 明确主次操作按钮

适用特点：

- 列表与表单切换频繁
- 支持快速创建与快速编辑

### 5.3 工作台 / 双栏页面模板

适用：发布中心、搜索运营。

固定区域：

- 左：输入与操作
- 右：状态与摘要
- 下：结果详情与日志

适用特点：

- 不是 CRUD 页面，而是任务型页面
- 更强调流程与状态

### 5.4 详情追踪页模板

适用：发布任务详情、审计详情、影响范围追踪。

固定区域：

- 顶部摘要
- 详情分组卡片
- 时间线 / 日志 / 关联对象

适用特点：

- 以追溯与排障为主
- 强调可读性和定位效率

## 6. 规范落地原则

- 后续改版优先抽通用样式和布局骨架，避免每页重复写一套按钮/表格/弹窗样式
- 优先统一高频页面，再扩展到次级页面
- 在不改业务逻辑的前提下先统一视觉和交互
- 页面实现若与本规范冲突，以本规范为准
