# 后台关键页面体验统一化说明稿

## 1. 文档目的

本文档基于后台体验统一化规范，补充首批高频页面的具体问题、改版目标与页面骨架建议，供产品、设计、研发共同评审。

本说明稿不直接输出视觉稿，而是明确页面为什么要改、应该改成什么结构、哪些地方需要统一。

## 2. Users 页面说明

### 当前问题

- 页面文案、按钮、表格、弹窗风格与其他页不稳定
- 列表页和弹窗表单虽已基本成型，但仍缺统一后台模板约束
- 图标按钮较多，操作可读性一般

### 改版目标

- 收口为“管理列表 + 弹窗表单”标准模板
- 明确主操作、批量操作、行内操作层级
- 强化角色分配和站点管理员绑定说明

### 推荐骨架

- 顶部：页面标题 + 简述 + 新建用户按钮
- 中部：搜索区 + 批量操作区
- 主体：用户表格
- 底部：分页
- 弹窗：基础信息 / 角色分配 / 管理站点 3 个逻辑分区

### 关键交互收口点

- 批量操作固定放搜索区下方或右侧组合位
- 重置密码建议使用“图标 + tooltip + 明确确认”
- 若选择 `site_admin`，管理站点字段必须高亮强调

## 3. Categories 页面说明

### 当前问题

- 页面同时承担树结构、模板配置、状态管理、影响查看，信息密度偏高
- 模板区和配置区缺少明显分组
- 树表混合场景容易造成阅读负担

### 改版目标

- 保留树表混合能力，但按“列表区 / 配置区 / 风险操作区”重构信息结构
- 模板相关字段独立成一组
- 影响查看与移动操作弱化为次级动作

### 推荐骨架

- 顶部：页面标题 + 站点切换 + 新建栏目
- 中部：搜索 / 状态筛选
- 主体：栏目树表
- 弹窗：基础信息 / 显示规则 / 模板配置 / SEO 设置 四组

### 关键交互收口点

- 模板配置必须独立分组展示
- 移动、影响查看、删除统一收口到操作列
- 树级缩进与状态标识需要统一视觉规则

## 4. Sites 页面说明

### 当前问题

- 当前同时存在平台视角和站点管理员视角，页面语义容易不统一
- 站点列表、站点配置和状态信息可能混在同一层

### 改版目标

- 平台管理员视角保持“站点列表页”
- 站点管理员视角保持“单站点配置页”
- 同一页面内明确区分列表管理与配置详情

### 推荐骨架

- 平台管理员：列表页模板
- 站点管理员：配置页模板或单卡片工作区模板

### 关键交互收口点

- 站点状态、发布状态、组织归属必须有统一展示位
- 避免把“站点列表”和“站点配置表单”无层级混放

## 5. PublishCenter 页面说明

### 当前问题

- 页面功能完整，但信息密度偏高
- 输入区、影响区、任务区、详情区的主次关系仍可进一步收口
- 告警、索引、回滚、审计虽然有分组，但视觉层级还可以更清晰

### 改版目标

- 收口为“工作台 / 双栏页面模板”标准样式
- 明确“先输入 -> 再校验 -> 再执行 -> 再追踪”的流程顺序
- 强化任务结果和风险提示层级

### 推荐骨架

- 顶部：页面标题 + 说明
- 上部：左侧发布入口，右侧校验结果
- 中部：影响范围 / 历史任务
- 详情：任务概览 / 影响项 / 产物 / 审计 / 回滚 / 日志

### 关键交互收口点

- 校验结果与影响范围必须视觉区分
- “建议整站发布”“索引告警”“执行失败”需要固定告警层样式
- 详情弹窗应统一为追踪型详情模板

## 6. SearchOps 页面说明

### 当前问题

- 页面已具备运营价值，但和发布中心之间的工作台风格还未完全统一
- 统计、重建、诊断入口同处一页，后续容易继续膨胀

### 改版目标

- 作为轻量工作台页与发布中心风格对齐
- 强化“状态统计 / 手动操作 / 诊断入口”三段式结构
- 为后续搜索运营深化保留扩展位

### 推荐骨架

- 顶部：页面标题 + 统计窗口
- 上部：索引状态卡片
- 中部：站点索引 / 对象索引操作区
- 下部：热词 / 零结果词 / 低结果词诊断区

### 关键交互收口点

- 诊断词的“补内容”入口保持统一视觉样式
- 不把搜索运营页做成复杂 BI，保持轻量高频可用

## 7. 不在本阶段修改的点

- 不改动任何后端接口
- 不改动权限模型和发布逻辑
- 不重做后台信息架构
- 不引入完整设计系统工程化实现

本阶段只为后续页面统一化改版提供足够明确的页面级实施依据。

## 8. 当前实施状态（2026-04-01）

本说明稿中首批和后续关键页面已陆续进入实际实现。当前状态如下：

- 已落地：`Users`、`Categories`、`Sites`、`PublishCenter`、`SearchOps`
- 已扩展落地：`Topics`、`Media`、`NavigationManagement`、`Menus`、`Roles`、`Permissions`
- 已补齐统一：`Content`、`Review`、`Dashboard`
- 已统一主骨架但仍保留较多旧局部样式：`Templates`、`PublishCenter`

后台体验统一化已进入维护态；后续仅按 `docs/21-admin-ux-residual-checklist.md` 处理零散维护项。
